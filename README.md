# GitReady 2.0

A simple website project created to practice Git and GitHub collaboration workflows.

## Visual

The project is a simple interactive webpage containing a heading, description, and button.
![GitReady 2.0 Screenshot](<Screenshot 2026-09-19 at 12.42.59.png>)

## Tech Stack

- HTML
- CSS
- JavaScript
- Git
- GitHub

## Features

- Responsive basic webpage layout
- Custom styling with CSS
- Interactive button using JavaScript
- GitHub Pull Request workflow

## Contribution

This project was completed individually as a simulation of a collaborative Git and GitHub workflow.

The workflow simulated:
- Initial HTML development on `main`
- Styling development on the `styling` branch
- JavaScript development on the `scripting` branch
- Pull Requests from feature branches to `main`
- Merging completed features into `main`

## What I Learned

- How to create and manage Git branches
- How to commit changes
- How to push branches to GitHub
- How to create Pull Requests
- How to merge feature branches into `main`
- How GitHub tracks changes between branches
- How HTML, CSS, and JavaScript work together
